How to Play

⚠️ The AI moves first by default, but you can change this using the "FIRST" button.

1. Tap any empty cell to place your O.

2. The AI uses Minimax + Fork Strategy to try and trap you.

3. If you go second, winning is mathematically impossible. If you go first, you might be able to force a tie, but don't make a single mistake!
